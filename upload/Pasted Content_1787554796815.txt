SECTION 11 — DATABASE SECURITY
====================================================

Enable Row Level Security on EVERY user-owned table.

NO EXCEPTIONS.

For tables directly owned by user:

SELECT:

auth.uid() = user_id

INSERT:

auth.uid() = user_id

UPDATE:

auth.uid() = user_id

DELETE:

auth.uid() = user_id

For related tables:

Verify ownership through parent relationship.

Example:

Chapter:

User may only access chapter if parent subject belongs to auth.uid().

IMPORTANT:

Never trust user_id sent by browser.

The database must enforce ownership.
